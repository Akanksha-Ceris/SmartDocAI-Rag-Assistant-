# SmartDocAI-Rag-Assistant-
SmartDoc AI is a Retrieval-Augmented Generation (RAG) based chatbot that allows users to upload multiple PDFs and ask intelligent questions using Streamlit, LangChain, and Google Gemini API.


An AI-powered document question-answering system built using LangChain, FAISS, Gemini, and Streamlit.

## Features
- PDF Upload
- Semantic Search
- RAG Architecture
- Gemini-powered Answers

## Tech Stack
- Python
- Streamlit
- LangChain
- FAISS
- Gemini API
- Sentence Transformers
